# 任务清单：坦克大战网页联机版

任务按依赖顺序排列，每项标注对应的需求编号。已完成项标记为 `[x]`，未开始的保持 `[ ]`。

## 阶段一：地图与绘制

- [x] 1. 实现地图查询接口
  - 1.1 `GameMap` 实体映射 `game_map` 表，`seed` 使用 JSON 列存二维数组
  - 1.2 实现 `GameMapController` → `GameMapService` → `GameMapRepository` 三层
  - 1.3 地图不存在时抛 `BusinessException(404)`
  - 1.4 编写控制器测试，覆盖 200、404、非法 ID 三种情况
  - _Requirements: 1.1, 1.3_

- [x] 2. 前端加载并绘制地图
  - 2.1 `GameView` 挂载时请求 `/api/game/maps/1`
  - 2.2 `mapLoader.drawMap` 按材质编号逐格贴图
  - 2.3 使用离屏画布缓存底图，避免每帧重绘 1040 个格子
  - 2.4 材质编号未配置时抛出明确错误
  - _Requirements: 1.2, 1.3, 1.4_

- [x] 3. 键盘输入与朝向
  - 3.1 方向键与 WASD 映射为 0~3
  - 3.2 多键按下时以最后按下的为准
  - 3.3 画布或窗口失焦时清空按键状态
  - _Requirements: 2.3, 2.4_

## 阶段二：战场规则（本人负责）

- [x] 4. 坦克移动
  - 4.1 新建 `playerMovement.ts`，实现纯函数 `movePlayer(player, direction, dt, bounds)`
  - 4.2 速度 72 像素/秒，位移 = 速度 × dt
  - 4.3 单帧 dt 上限 0.1 秒，防止标签页切回时瞬移
  - 4.4 松开按键立即停止，保留朝向
  - 4.5 编写纯函数测试，覆盖四方向位移与 dt 换算
  - _Requirements: 2.1, 2.2_

- [x] 5. 地图边界限制
  - 5.1 坐标上限为画布尺寸减坦克尺寸
  - 5.2 使用 clamp 保证坦克完整可见
  - 5.3 测试四个边界方向均不越界
  - _Requirements: 3.1, 3.2, 3.3_

- [ ] 6. 墙体碰撞
  - 6.1 像素坐标转格子坐标：`col = floor(x / tileSize)`
  - 6.2 取坦克四个角所在的格子，任一角不可通行则该位置非法
  - 6.3 砖墙、钢墙、河流视为不可通行；树林、冰面视为可通行
  - 6.4 移动前先试算目标位置，非法则保持原位
  - 6.5 编写纯函数测试，覆盖贴墙行走与斜向撞角
  - _Requirements: 4.1, 4.2, 4.3_

- [ ] 7. 发射子弹
  - 7.1 定义 `BulletState`，记录归属玩家、坐标、方向
  - 7.2 开火冷却 300 毫秒，冷却期间忽略请求
  - 7.3 同一玩家在场子弹上限 1 颗
  - 7.4 子弹速度 240 像素/秒，沿生成时方向直线移动
  - _Requirements: 5.1, 5.2, 5.3, 5.4_

- [ ] 8. 子弹命中判定
  - 8.1 命中砖墙：销毁该格并移除子弹，破坏记录写入本局 `destroyedCells`
  - 8.2 命中钢墙：移除子弹，墙体保留
  - 8.3 命中坦克：扣除生命值并移除子弹
  - 8.4 飞出边界：直接移除
  - _Requirements: 6.1, 6.2, 6.3, 6.4_

- [ ] 9. 生命值与对局结束
  - 9.1 初始生命值 3 点
  - 9.2 生命值归零立即判负
  - 9.3 双方同帧归零判平局
  - 9.4 结束后停止物理推进并显示结算
  - _Requirements: 7.1, 7.2, 7.3, 7.4_

## 阶段三：房间与连接（搭档负责）

- [ ] 10. WebSocket 端点与身份鉴权
  - 10.1 注册 `/ws/game`，配置握手拦截器
  - 10.2 握手时复用 `CurrentUserService` 校验登录 Session
  - 10.3 未登录拒绝握手，登出后关闭关联连接
  - 10.4 连接登记表维护 userId → 有效连接
  - _Requirements: 10.2_

- [ ] 11. 房间管理
  - 11.1 创建房间，生成不重复的房间号，创建者为房主
  - 11.2 加入房间，校验存在性、状态与空位
  - 11.3 准备状态切换并广播 `room:state`
  - 11.4 退出房间，房主退出时转移房主
  - _Requirements: 8.1, 8.2, 8.3, 9.1, 9.2, 9.3_

- [ ] 12. 开局流程
  - 12.1 房主发起开局，要求两人在线且已准备
  - 12.2 读取地图模板并深复制为本局独立副本
  - 12.3 发送 `game:init`，双方确认加载后发送 `game:start`
  - 12.4 加载超时 30 秒退回等待状态
  - _Requirements: 9.3, 1.3_

## 阶段四：联机同步

- [ ] 13. 输入上报与状态同步
  - 13.1 客户端以约 20 次/秒上报完整按键状态
  - 13.2 服务端按 50ms 固定步长推进，计算结果
  - 13.3 服务端以 10 次/秒推送 `game:state` 快照
  - 13.4 客户端按快照插值绘制，不自行修改坦克位置
  - _Requirements: 10.1, 10.2_

- [ ] 14. 断线重连
  - 14.1 检测到断开后保留席位 15 秒
  - 14.2 同账号重连时替换旧连接，发送全量快照
  - 14.3 超时判负，双方都离线则中止对局
  - _Requirements: 10.3, 10.4_
