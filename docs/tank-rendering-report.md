# 坦克画面流畅度与标记调整

日期：2026-11-18。前端修改已完成，等待手动验收。

## 修改内容

- 联机坦克和子弹都按 `requestAnimationFrame` 补帧。子弹不再每收到一份网络快照才跳到新位置。
- 补帧时长按服务端 tick 间隔计算；坦克转弯按横、纵两段路径衔接，长时间断线和结束时直接同步真实位置。
- 地形和树林分别缓存为画布图层；开局绘制一次，砖墙只在服务端确认被击毁后清除，逐帧不再遍历整张地图重画树林。
- 缓存主画布上下文，关闭图片平滑，使用不透明主画布，减少重复绘制。
- 移除坦克外框、“你 / 敌军 / 队友”头顶文字及文字底色，移除画布焦点边框；保留素材颜色与血条。
- 单人模式移除额外描边和树林中的坦克方框；画布继续逐帧绘制，计分等 Vue 文本最多每 100ms 更新一次。

## 本机浏览器对比

隔离 Chrome、相同合作地图、两个测试账号、方向键移动后持续射击，分别采样 150 个有子弹的画面帧：

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 主画布绘制帧率 | 60.02 FPS | 59.99 FPS |
| 子弹可见位置更新 | 8.06 次/秒 | 56.77 次/秒 |
| 每帧图片绘制调用均值 | 33.97 | 11.01 |
| 样本中的头顶文字绘制 | 543 次 | 0 次 |
| 样本中的矩形描边 | 543 次 | 0 次 |
| Canvas CSS 边框 | 2px | 0px |

原来画布本身持续重画，但子弹坐标只随低频快照变化，视觉上存在明显跳动。本次提高的是运动补帧和绘制效率；没有把服务端网络同步频率当作屏幕帧率。实际表现仍取决于设备、显示器刷新率和网络。
